# 车牌录像

面向行人近距离记录移动车辆的独立 CameraX 应用。点击桌面图标后自动判断环境光、启动后置主摄并开始录像；红色停止按钮显示当前录像时长，点击按钮或按音量键后自动保存并进入录像列表。

录像页右上角可进入“录像列表”。进入列表时会放弃并删除当前正在录制的片段，列表以“视频缩略图｜时间｜车牌号”展示已经保存的视频；车牌号可点击手动录入并自动保存。列表中的红色三角按钮开始新录像，“删除全部”经过确认后会从手机中永久删除当前列表的所有视频及其车牌号标注。

## 工作方式

- 固定后置主摄 1×、横屏和 16:9；预览完整显示实际录像画面，避免近距离侧拍时裁掉车辆或车牌
- 录像页和列表页使用沉浸式全屏，状态栏只允许通过系统手势临时显示，松手后自动隐藏
- 左上角参数强制单行显示；录像时长只显示在红色停止按钮上
- 录像页固定横屏，录像列表固定竖屏并使用适配窄屏的三列布局
- 环境光达到 800 lx 时优先 4K/30fps，利用更多空间细节辨认车牌；普通与低光环境优先 1080p/30fps，降低噪声和编码压力
- 车牌曝光补偿：强光/普通光 -0.7 EV，低光 -1.0 EV，减少反光车牌过曝
- 低于 100 lx 时自动开启后置常亮补光灯；普通和强光环境保持关闭，录像页显示相机实际补光状态
- 视频保存到系统媒体库的 `Movies/CarPlateRecorder`
- 录像列表直接读取上述媒体库目录，点击缩略图可播放视频
- 车牌号标注按视频 ID 保存在应用本地，不修改原视频文件
- 目标 vivo 的第三方 CameraX 能力只公开到 30fps；系统相机里的 60fps 属于厂商私有通道，不能由标准 CameraX 稳定调用

首次启动会请求相机和麦克风权限。相机权限是必需的；拒绝麦克风权限时仍会录制无声视频。

## 构建

需要 JDK 17 和 Android SDK 35：

```powershell
.\gradlew.bat assembleDebug
```

调试 APK 生成在 `app/build/outputs/apk/debug/app-debug.apk`。
